# 🎨 Satvikesh Reddy's Portfolio

A modern, playful portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. Features bold colors, smooth animations, and unique dithering effects.

## ✨ Features

- **Modern React Stack**: Built with React 19, TypeScript, and Vite for blazing-fast development
- **Beautiful Animations**: Powered by Framer Motion for smooth, professional animations
- **Dithering Effects**: Unique retro-style dithering patterns throughout the design
- **Fully Responsive**: Works perfectly on all devices
- **Bold Design**: Playful interface with vibrant colors (#ffeb3b, #4ecdc4, #ff6b6b)
- **Performance Optimized**: Fast loading with optimized builds

## 🚀 Tech Stack

- **React 19** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool & dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **ESLint** - Code linting

## 📦 Installation

\`\`\`bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
\`\`\`

## 🎨 Customization

### Colors
The theme colors are defined in \`tailwind.config.js\`:
- **Primary**: #ffeb3b (Yellow)
- **Secondary**: #4ecdc4 (Teal)
- **Accent**: #ff6b6b (Red)
- **Dark**: #222 (Nearly Black)

### Dithering Patterns
Three unique dithering patterns are available:
- \`dither-pattern-1\`: Radial dot patterns
- \`dither-pattern-2\`: Diagonal line patterns
- \`dither-pattern-3\`: Conic gradient patterns
